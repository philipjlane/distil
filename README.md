# distil

Local-first meeting notes for macOS. Records your meetings (mic + system audio),
transcribes them on-device with whisper.cpp, and distils the transcript into
structured notes with a local LLM via Ollama. Nothing leaves your Mac.

See [PLAN.md](PLAN.md) for the v1 plan and architecture.
